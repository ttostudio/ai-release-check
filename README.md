# 公開前チェック

AIで作ったWebアプリを公開する前の自己点検ツール。無料・登録不要。回答はブラウザの localStorage に保存し、Markdown に書き出せます。外部送信・コード自動解析はしません。

## 使い方

GitHub Pages の公開URL（準備中）へアクセスするか、`python3 -m http.server 8000` を実行し `http://localhost:8000` を開いてください。ローカルでは `node --test checker.test.mjs` でデータとレポートを検証できます。

## 注意

自己申告に基づく作業リストです。安全性、網羅性、法令適合性を保証しません。秘密鍵や個人情報は入力しないでください。データはブラウザごとに残るため、共有端末では終了後にリセットしてください。
