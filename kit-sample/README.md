# 公開前検証キット：自作Next.jsサンプル（制作途中・未販売）

予約入力を題材にした模擬アプリです。予約は確定せず、入力を保存しません。個人情報を入れないでください。Next.js 16.3.6 / React 19.2.4 を固定し、`package-lock.json` を添付します。

## 再現手順

Node.js 20.9 以上を用意し、このディレクトリで実行します。

```sh
npm ci
npm test
npm run build
npm run start -- --port 3197
# 別の端末から
node tests/http-smoke.mjs
```

画面は http://127.0.0.1:3197/ 。人数を 5 に書き換えた API 直接送信でも HTTP 400 となることを確認します。`tests/http-smoke.mjs` は起動済みの本番ビルドに対する試験です。

## この教材で学べる範囲

- ブラウザ側の `min` / `max` だけでは不十分。`lib/validate.mjs` で API 入力を再検査する。
- 成功状態、入力エラー、通信失敗の表示を区別する。
- 単体テストと本番HTTPスモークを別々に実行し、実行結果を記録する。

これは **認証・予約確定・在庫管理・永続化・請求・負荷試験・アクセシビリティ監査を検証したサンプルではありません**。安全な実サービスの雛形としてそのまま公開しないでください。テストが通っても脆弱性がないことは保証しません。
